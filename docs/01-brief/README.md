# Brief

This stage captures the initial project brief before discovery begins.

The goal is to understand:

- what is being created
- why it is being created
- who it is for
- what success looks like
- what constraints already exist
- what is in and out of scope

## Outputs

- `client-brief.md`

## Exit criteria

Move to Discovery when:

- [ ] The project goal is understood
- [ ] The target users are identified
- [ ] The initial scope is defined
- [ ] Known constraints are documented
- [ ] Open questions are recorded
